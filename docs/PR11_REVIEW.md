# PR #11 compatibility revision — 2026-10-04

The contributor reported Omniverse scientific-notation import warnings and proposed six decimal places plus underscore filenames. The revision emits finite numeric URDF attributes in fixed decimal notation without truncating significant digits: tiny positive mass/inertia values stay positive, and joint axes/limits retain precision. Non-finite values are rejected. This affects both class-based and legacy URDF element builders, without rewriting names or mesh URIs as numbers.

Shared filename normalization uses underscores for spaces and retains occurrence instance suffixes and hierarchy. Consequently all exporters and mesh writers agree on filenames; names containing spaces change relative to prior releases. Sanitized occurrence-name collisions are checked during discovery. URDF, URDF+, and SDF writers also validate the actual emitted link and joint identities before writing XML; this catches distinct Fusion joints such as `Joint A` and `Joint_A` that now normalize to the same name. Class-based URDF retains distinct child-prefixed names. MJCF already checks sanitized joint identities in preflight. Existing XML files are preserved when a name collision stops an export.

73 unittest tests pass after integration with the root-frame, diagnostic and optional collision changes: six serialization tests cover tiny/large decimals, exact decimal roundtrip, zero handling, non-finite rejection, numeric-only XML rewriting, occurrence paths and filename collisions. Four writer-boundary regressions cover bare-joint collisions in URDF/SDF, existing-file preservation, and the class-based URDF/URDF+ naming conventions. Native CoACD and existing MJCF, release, localization and discovery tests pass.

The latest stable Isaac Sim 6.2 isolated asset importer accepts the tested class and legacy exports, small positive inertias, underscore filenames, repeated occurrences and multi-piece collision assets. A scientific-notation control also passes this target, so the older warning was not reproduced. See [the sourced validation report](ISAAC_IMPORT_VALIDATION.md) for exact packages, values, fixtures and reproducible commands. CI repeats the real isolated imports; no full Kit/physics run or live Fusion CAD validation is claimed. PR #17 is merged; broad validation of complex nested MJCF assemblies remains outside this change. The six-decimal global setting is intentionally not adopted because it can erase physically meaningful values.
